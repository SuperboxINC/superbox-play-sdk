# 휴대폰에서 테스트하기

먼저 `docs_read`로 `/test/local`을 읽어 지금 옵션을 확인해요.

## 엔진별 실행

| 엔진 | 방법 |
|---|---|
| Unity | 상단 메뉴 **Superbox Play > Test on Device**를 눌러 달라고 안내해요. WebGL 빌드 뒤 QR 창이 열려요. |
| Cocos Creator, Phaser, HTML5 | 웹 빌드 폴더를 만든 뒤 터미널에서 `npx superbox-play dev <빌드 폴더> --lan`을 실행해요. |

`--lan`은 빌드 폴더를 꼭 넣어야 해요. 서버는 계속 켜 두어야 하니 백그라운드로 실행하고, 끝나면 꺼 주세요.

터미널이나 창에 나온 QR 코드를 휴대폰 카메라로 찍어 달라고 안내해요. 휴대폰과 컴퓨터는 같은 Wi-Fi에 있어야 해요.

## 열리지 않을 때

1. 휴대폰과 컴퓨터가 같은 네트워크인지 확인해요. 게스트 Wi-Fi나 회사망은 기기끼리 연결을 막기도 해요.
2. 컴퓨터 방화벽이 서버 포트를 막고 있는지 확인해요.
3. 그래도 안 되면 콘솔에 올려서 미리보기 주소로 열어요. `release-check` 스킬의 순서를 따라요.

## 알아 둘 것

- 광고와 결제는 시뮬레이션으로 동작해요.
- 주소가 http라서 https가 필요한 브라우저 기능은 동작하지 않을 수 있어요. 실제 게임존에서 확인하려면 `build_preview` 주소를 쓰세요.
- 로컬 테스트를 했다고 해서 검수 요청 조건이 채워지지는 않아요. 검수를 요청하려면 `build_preview` 주소를 열어야 해요.
