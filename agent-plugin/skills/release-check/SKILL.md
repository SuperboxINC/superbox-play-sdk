# 출시 점검

먼저 `docs_read`로 `/launch/checklist`를 읽어요. 아래 순서대로 진행하고, 지금 어디까지 왔는지 사용자에게 알려 주세요.

## 1. 게임 정보

`game_info`로 `missing` 항목을 확인해요. 비어 있는 항목이 있으면 사용자에게 내용을 받아 채워요.

- 글자 항목은 `game_info_save`로 저장해요.
- 썸네일과 스크린샷은 `image_upload`로 받은 명령으로 파일을 올리고 `image_confirm`의 `mediaId`를 `game_info_save`에 넣어요.
- 아이콘은 `icon_upload`로 올리고 `icon_confirm`을 불러요.
- 소개 영상은 유튜브 주소 목록으로 `game_info_save`의 `videoUrls`에 넣어요.

이미지 규격은 `/launch/game-info`에서 확인해요. 규격에 맞지 않으면 파일을 임의로 늘리지 말고 사용자에게 알려 주세요.

항목을 다 채웠으면 `game_info_review_request`를 불러요. 도구 설명의 동의 다섯 가지를 사용자에게 그대로 보여 주고, 사용자가 동의한 항목만 넣어요. 대신 동의하지 마세요. 검수 중에 고치려면 `game_info_review_cancel`로 취소한 뒤 고쳐요.

빌드를 올리기 전에 게임을 먼저 알리고 예약을 받고 싶다면 `/launch/prereg`를 읽어요. 게임 정보가 승인되면 콘솔 ‘출시’ 화면에서 채널마다 사전예약을 열 수 있어요. 도구로는 열 수 없어서 콘솔에서 열어 달라고 안내해 주세요.

조직의 이용약관 · 개인정보 처리방침은 조직 관리자가 콘솔 ‘조직 정보’에서 넣어요. 넣으면 게임센터가 처음 여는 플레이어에게 동의를 받아서, 게임 안에 같은 동의 화면을 따로 만들지 않아도 돼요.

## 2. 패키지 만들기

`/package/cli`를 읽고 `superbox-play build`로 `.sbp`를 만들어요. Unity와 Cocos Creator는 메뉴 **Superbox Play > Build & Package**로도 만들 수 있어요. 만든 뒤 `npx superbox-play inspect <파일>`로 검증해요.

패키지는 버전이 올라가야 해요. 같은 채널에서 쓴 버전은 다시 쓸 수 없어요.

## 3. 올리기

1. `channels_list`로 채널을 보여 주고 어느 채널에 올릴지 사용자에게 확인받아요.
2. 파일 크기를 재서 `build_upload`를 불러요.
3. 결과의 `curl` 명령에 파일 경로를 넣어 실행해요. 경로에 빈칸이 있으면 따옴표로 감싸 주세요.
4. `build_upload_complete`를 불러요.
5. `build_upload_status`가 `ready`가 될 때까지 확인해요. `failed`면 결과의 이유를 사용자에게 알려 주세요.

## 4. 테스트

`build_preview`로 주소를 받아 사용자에게 보여 주고, 브라우저나 휴대폰에서 열어 달라고 해요. 이 주소를 연 빌드만 검수를 요청할 수 있어요. 대신 열었다고 말하지 마세요.

## 5. 검수 요청

이번 빌드에서 바뀐 점으로 출시 노트 초안을 쓰고 사용자에게 확인받아요. 그다음 `build_review_request`를 불러요. 첫 출시라면 게임 정보도 검수 중이거나 승인된 상태여야 해요.

검수는 슈퍼박스 검수 담당이 해요. `build_detail`이나 `builds_list`로 결과를 확인할 수 있어요. `build_review_cancel`로 취소한 빌드는 다시 요청할 수 없어서 버전을 올려 새로 올려야 해요. 사용자에게 먼저 확인받아 주세요.

## 6. 출시와 되돌리기

새 버전 출시는 도구로 할 수 없어요. 검수에서 승인되면 콘솔의 ‘출시’ 메뉴에서 직접 출시해 달라고 안내해 주세요. 첫 출시는 게임 정보도 승인돼 있어야 해요.

출시한 버전에 문제가 있으면 `build_rollback`으로 전에 그 채널에 출시한 버전으로 되돌릴 수 있어요. 버전과 채널을 사용자에게 다시 확인받고, 사용자가 명확히 요청했을 때만 불러 주세요. 그 채널에 나가 있던 버전이 바로 바뀌어요.

## 콘솔에서만 하는 일

새 버전 출시, 사전예약 열기와 닫기, 채널에서 내리기, 운영 종료, 조직 정보(약관 포함), 상품 등록, 미션 만들기, 충전과 정산, 멤버, API 키는 도구로 할 수 없어요. 필요하면 콘솔에서 해 달라고 안내해 주세요.
